Welcome to contribute **compatibility across multiple Minecraft versions** and other fixes to Virtual Redstone Wire.

## Contribution Guidelines

### Version Compatibility Guidelines

If you want to add version compatibility, please submit an **Issue** first to specify the target version. The maintainer will create the corresponding version directory and make the initial implementation.

**Do not make compatibility versions on your own and submit a PR**

## How to Contribute

### 1. Submit an Issue
- [Open a new Issue](https://github.com/JularDepick/Virtual-Redstone-Wire/issues/new)
- Describe the bug you found or state your expectations
- Submit the Issue

### 2. Contribute Code
- [Fork this project](https://github.com/JularDepick/Virtual-Redstone-Wire/fork)
- Complete the code changes on your fork branch
- [Create a Pull Request in this project](https://github.com/JularDepick/Virtual-Redstone-Wire/compare)
- Submit the PR and wait for review
